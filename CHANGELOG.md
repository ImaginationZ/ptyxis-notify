# Changelog

All notable changes to this project are documented here. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-17

### Added

- `ptyxis-notify` with `notify`, `start`, `done` and `run` commands.
- zsh integration that adds the "command started" signal missing from
  VTE's `vte.sh`, usable as a zsh plugin.
- Examples for Claude Code, Codex CLI, Aider and Gemini CLI.
- Test suite and CI (shellcheck, dash, bash, busybox, zsh).
